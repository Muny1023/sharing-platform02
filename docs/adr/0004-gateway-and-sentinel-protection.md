# 在网关集中执行入口治理

状态：accepted

所有前端请求继续访问网关，由网关负责路由、CORS、入口 JWT 校验和 Sentinel 路由治理。Sentinel 规则通过 Nacos 动态配置：认证接口保留每 IP 三秒最多十次的入口限流，其他 `/api/**` 路由初始按每实例每秒一百次保护，并在错误比例达到百分之五十且满足最小请求数后熔断。降级响应保持 `RestBean` 结构，状态码使用 429 或 503。

## 考虑过的方案

- 只在各业务服务限流：无法在请求进入系统前统一保护，也会重复实现入口策略。
- 只依赖现有认证过滤器：它不能承担路由级熔断和动态规则管理。

## 后果

业务服务仍需校验 JWT，不能把网关当作唯一信任边界；原有 `FlowLimitFilter` 继续保留，用于认证接口的 IP 级保护。
